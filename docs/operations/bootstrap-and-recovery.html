Bootstrap and recovery

First run​

If the database has no users, My Clawster creates an operator account automatically.

Recovery priorities​

  1. database integrity
  2. runtime secrets
  3. provider integration health
  4. bindings and mappings
  5. app and API reachability

Practical advice​

Keep recovery procedures close to the owning deploy roots, not just the docs site.
