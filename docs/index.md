# My Clawster Docs

My Clawster is a self-hostable cluster management platform for teams running their
own agent infrastructure.

Start here when you need to understand the operating model:

- Isolated workspaces for agent teams and credentials.
- Provider paths for VPS, cloud, Kubernetes, and hybrid deployments.
- Bring-your-own-key routing across hosted and local models.
- Audit-friendly operations for gateways, workers, and support claws.

The documentation is intentionally short for now while the website structure is
being shaped around the product.
