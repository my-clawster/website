Admin portal tour

The admin portal is where operators manage the platform, not just consume it.

Core areas​

  • Dashboard
  • Product to Resource workspace
  • Providers
  • Integrations
  • Claws telemetry
  • Users
  • Audit
  • Settings

What makes it different from the OSS app​

The OSS app is for end users managing their own clawsters.

The admin portal is for operators managing:

  • the commercial catalog
  • provider readiness
  • bindings and health
  • platform-level governance

Use it when​

  • a new provider lane needs to be introduced
  • a catalog path is incomplete or unhealthy
  • an audit trail is needed for changes
  • a binding or integration must be repaired
