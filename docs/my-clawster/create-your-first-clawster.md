# Create your first clawster

A clawster is the logical home for the claws that serve one team, project, or workload family.

## Typical flow

1. Sign in or create your account
2. Create a cluster
3. Choose a service path based on an offer and product offering
4. Select service options such as compute profile, OS image, and region
5. Provision your first claw
6. Watch status and bindings from the dashboard

![Single-provider clawster topology](/wizard-diagrams/clawster-single-vps.svg)

## Before you click provision

Make sure your environment has:

- at least one active provider path
- a compatible product offering
- service options that resolve cleanly to the provider

If provisioning fails, the most common causes are missing provider bindings, missing activation mappings, or inactive catalog records.

## Good first setup

For most first runs, start with:

- one cluster
- one provider path
- one primary claw role
- one clear region

Then expand into hybrid or multi-provider workflows once the model is familiar.
