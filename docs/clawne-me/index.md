# Clawne Me

**Clawne Me helps you build AI assistants that actually fit how you work — without infrastructure decisions getting in the way.**

You describe what you want help with. Clawne Me walks you through the rest: role, tone, memory, tools. You iterate until it feels right. The platform underneath stays invisible until you need it.

It runs on top of My Clawster, but you do not need to understand the platform to get started.

![Clawne Me user flow](/img/my-clawster/clawne-me-user-flow.svg)

## What a Clawne is

A Clawne is a personal AI assistant you configure and own. It has:

- a **role** — what it is optimized to help with
- a **personality** — how it communicates
- optional **memory** — what it should retain across conversations
- optional **tools** — what it can do beyond conversation

You can have multiple Clawnes for different jobs. A research Clawne is not the same as a project-management Clawne.

## How it works

1. You start with a goal — one sentence is enough.
2. Clawne Me helps you shape the role and tone.
3. You launch it and test it with real prompts.
4. You add memory and tools when the workflow proves it needs them.
5. You keep iterating. A Clawne gets better the more you use it.

The best early Clawnes are narrow, specific, and easy to improve.
